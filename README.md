# Hi, I'm Fabricio

I'm a mid-level developer in Curitiba, Brazil. I work mostly with C# and .NET on the backend and Angular on the front end.

At my day job I build integration portals and APIs that replace manual steps in administrative and tax workflows.

## What I work on

- REST APIs in .NET 8 and .NET 10, with Clean Architecture and Entity Framework
- Angular front ends in TypeScript
- Integrations with third-party APIs and with Oracle and SQL Server databases
- Data extraction from Brazilian tax documents (NF-e, CT-e, boletos) using the Claude API
- Process automation with AutomationEdge and Python
- Deploys with Docker and NGINX on Linux
